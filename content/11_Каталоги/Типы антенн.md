# Типы антенн

> [!info] Назначение
> Быстрый каталог типов антенн. Для конкретной модели или самодельной конструкции нужно создавать отдельную карточку.

| Тип                      | Где применяют                     | Что важно проверить                | Статус           |
| ------------------------ | --------------------------------- | ---------------------------------- | ---------------- |
| Dipole                   | Радиоканал, видео, базовые сборки | длина плеч, частота, ориентация    | черновик         |
| Monopole                 | Компактные приемники и модули     | земля, корпус, размещение          | черновик         |
| Cloverleaf / skew planar | Аналоговое видео                  | поляризация, качество пайки, КСВ   | черновик         |
| Patch                    | Прием видео, направленный прием   | направление, усиление, поляризация | черновик         |
| Helical                  | Дальний направленный прием        | шаг, витки, согласование, размер   | требует проверки |
| Moxon / Yagi             | Направленные радиолинки           | размеры, частота, диаграмма        | требует проверки |
