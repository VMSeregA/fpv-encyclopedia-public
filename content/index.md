# FPV Энциклопедия

> [!info] Назначение
> Это публичная база знаний по FPV: радиоканал, видео, антенны, питание, сборка, прошивки, диагностика и полевой опыт. Главный принцип - отделять проверенные факты от черновиков и непроверенных наблюдений.

> [!warning] Правило безопасности
> Если материал влияет на питание, пайку, прошивку, частоты, дальность, надежность связи или риск повреждения оборудования, у него должен быть явный статус проверки и описание условий теста.

## Статусы качества

| Статус             | Когда ставить                                                               | Как читать                                     |
| ------------------ | --------------------------------------------------------------------------- | ---------------------------------------------- |
| `проверено`        | Есть измерение, повторяемый тест, надежный источник или устойчивая практика | Можно использовать как базовую опору           |
| `полевой опыт`     | Есть реальное наблюдение, но условия могут влиять на результат              | Полезно, но нужно сверять со своими условиями  |
| `требует проверки` | Решение выглядит рабочим, но подтверждений мало                             | Нельзя подавать как окончательную рекомендацию |
| `черновик`         | Материал неполный                                                           | Нужна доработка перед публичным использованием |
| `устарело`         | Информация сохранена для истории                                            | Нужна повторная проверка перед применением     |

## С чего начать наполнение

1. Открой [[00_Главная/Правила качества|Правила качества]].
2. Выбери подходящий шаблон в [[90_Шаблоны/Шаблон статьи|90_Шаблоны]].
3. Добавь материал в правильный раздел.
4. Если есть PDF, фото, прошивка, лог или таблица, положи исходник в `99_Материалы` и дай ссылку из заметки.
5. Укажи статус проверки и условия, при которых вывод был получен.
