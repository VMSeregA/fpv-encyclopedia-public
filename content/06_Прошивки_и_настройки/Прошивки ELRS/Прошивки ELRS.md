# Прошивки ELRS

> [!info] Назначение
> Здесь собираются материалы по прошивкам ExpressLRS: версии, цели прошивки, способы обновления, откат, типовые ошибки и проверка после прошивки.

## Что добавлять

- точную версию ELRS;
- тип устройства: TX-модуль, RX-приемник, AIO, backpack;
- target/target name из ExpressLRS Configurator;
- способ прошивки: Wi-Fi, UART, Betaflight passthrough, EdgeTX/Backpack;
- binding phrase или UID, если это важно для проверки;
- результат проверки после прошивки.
