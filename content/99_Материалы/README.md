# Материалы

Эта папка предназначена для исходников, на которые ссылаются заметки:

- PDF-инструкции;
- фотографии сборок и измерений;
- прошивки;
- CLI-дампы;
- таблицы;
- логи;
- архивы;
- скриншоты приборов и настроек.

## Правило

Файл в этой папке должен быть связан хотя бы с одной заметкой, где написано, что это за файл, откуда он взят и зачем он нужен.
